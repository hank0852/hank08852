# Game Daily Hub｜ゲームの日課管理

遊んでいるゲームのログインとデイリーミッションを、日本語の画面で管理するサイトです。ゲームやチェック項目はブラウザーから追加できます。HTML・CSS・JavaScript で動作し、npm のインストール、ビルド、PHP、データベースは不要です。

## 使い方

1. `games.html` のゲーム管理ページで、好きなゲームを追加します。
2. 各ゲームには「デイリーミッション」と「ログイン」が最初から用意されます。
3. `tasks.html` のタスク管理ページで、必要なチェック項目を追加します。終わった項目にチェックを入れると、進捗に反映されます。
4. `index.html` の今日の概要で、未ログインのゲームや未完了のタスクを確認します。ゲーム一覧はゲーム管理ページにあります。

ゲームのイベント・お知らせページはありません。リマインダーはサイト内の表示で、プッシュ通知やメール通知は送信しません。

## VS Code で開く

1. [GitHub のリポジトリ](https://github.com/hank0852/hank08852)から **Code → Download ZIP** でダウンロードし、展開します。
2. VS Code の「ファイル → フォルダーを開く」で、展開したフォルダーを開きます。
3. 拡張機能 **Live Server** をインストールします。
4. `index.html` を開き、右下の **Go Live** を押します。
5. 同じブラウザーで、サイトのナビゲーションから各ページを開きます。

HTML ファイルをダブルクリックして開く `file://` 形式では、ブラウザーによって保存が使えなかったり、ページ間でデータを共有できなかったりします。Live Server で開く方法をおすすめします。

Python がインストールされている場合は、Live Server の代わりにプロジェクトのフォルダーで次のコマンドを実行できます。

```sh
python3 -m http.server 8001 --bind 127.0.0.1
```

ブラウザーで `http://127.0.0.1:8001` を開きます。環境によっては `python3` の代わりに `python` を使用します。終了するときはターミナルで `Ctrl+C` を押します。

## データの保存と毎日のリセット

ゲーム、追加したタスク、チェック状態は、ブラウザーの `localStorage` に保存されます。同じブラウザー・同じサイトのアドレスで開けば、再読み込み後もデータを使えます。

- チェック状態は、端末の現地時間で日付が変わるとリセットされます。サイトを閉じていた場合は、次に開いたときにリセットされます。
- 登録したゲームとタスクの内容は、日付が変わっても残ります。
- リセット時刻は現地時間の午前 0 時です。各ゲーム独自の更新時刻には連動しません。
- アカウントやサーバー保存はなく、別の端末やブラウザーには同期されません。
- `localhost` と `127.0.0.1`、異なるポート番号、GitHub Pages はそれぞれ別の保存先になります。普段は同じアドレスを使ってください。
- ブラウザーのサイトデータを削除すると、保存内容も削除されます。プライベートブラウズでは、終了時にデータが消える場合があります。

## ファイル構成

- `index.html`：今日の概要と未完了項目。
- `games.html`：ゲームの一覧と追加フォーム。
- `tasks.html`：タスクのチェックと追加フォーム。
- `styles.css`：共通の配色、レイアウト、スマートフォン向けの表示。
- `store.js`：データの保存と日付ごとのチェック状態の管理。
- `app.js`：各ページの表示とフォーム操作。
- `assets/*.svg`：本プロジェクトで制作した抽象イラスト。ゲーム公式の画像ではありません。
- `tests/store.test.cjs`：データ管理の自動テスト。

外部フォント、外部画像、CDN に依存しません。色や余白は `styles.css` で変更できます。ゲームやタスクの追加にはコードの編集は必要ありません。

## GitHub Pages で公開する場合

リポジトリの **Settings → Pages** を開き、Source に **Deploy from a branch**、Branch に **master**、フォルダーに **/(root)** を指定して保存します。公開が完了すると、Pages の設定画面からサイトを開けます。

静的サイトとして動作するため、GitHub Pages でもゲームやタスクを追加できます。データの保存先は閲覧している人のブラウザーで、GitHub のファイルが書き換わることはありません。

## 開発時の確認

Node.js がある場合は、プロジェクトのフォルダーでデータ管理のテストを実行できます。通常のサイト利用に Node.js は不要です。

```sh
node --test tests/store.test.cjs
```

ブラウザーでは、ゲームの追加、タスクの追加、チェック操作、ページを移動したときの進捗、再読み込み後の保存内容を確認してください。

問題集の `quiz-practice` は別の独立したプロジェクトです。このサイトの操作で問題集の内容が変わることはありません。
